# 标签开视页 · WPS 日历工作台

一款 Microsoft Edge 浏览器新标签页增强插件（Manifest V3，与 Chrome 兼容）。

**搜索 + 常用站点导航 + WPS 日历日程，一页搞定。** 登录 WPS 账号后，可在插件内新增 / 编辑 / 删除日程，并实时同步到 WPS 日历；未登录时为本地模式，离线可用。

---

## 功能特性

- **多引擎搜索**：内置必应 / 百度 / Google 一键切换，**支持在设置中新增自定义搜索引擎**（名称 + 搜索地址），回车直达（按 `/` 或 `Ctrl+K` 快速聚焦）
- **快速导航**：站点图标网格，内置 11 个分类（工作/日常/国内AI/国外AI/设计/购物/PPT演示/党建政务/视频素材/常用工具/数据可视化）；支持分组增删改、拖拽排序、favicon；**支持分组配置导出 / 导入（JSON）**；每个分组 tab 可一键 ✕ 删除
- **WPS 日历**：
  - 月历视图 + 当日日程列表
  - 插件内**新增 / 编辑 / 删除**日程
  - 弹出页面登录 WPS 账号后**实时同步**到 WPS 日历（无需 APPID，个人 / 企业账号均可）
  - 未登录自动降级为本地模式，数据保存在本机
- **小组件系统**：天气（近一周）/ 迷你日历（含农历）/ 待办清单 / 便签，设置中**自由添加 / 移除**，即时生效
- **数字时钟**：黑体大号时间 + 日期星期
- **个性化**：浅色 / 深色 / 跟随系统主题，天气城市设置，日历显示开关

## 快速开始（本地加载）

1. 打开 Edge，地址栏输入 `edge://extensions`
2. 打开右上角「开发人员模式」开关
3. 点击「加载解压缩的扩展」，选择本项目目录：`edge-newtab-extension/`
4. 新建标签页，即可看到「标签开视页」

> 安装后如需查看扩展 ID：`edge://extensions` 中本扩展卡片上会显示。

## WPS 日历登录与同步（弹出页面授权，无需 APPID）

插件采用与「金山云文档 DSH 插件」一致的 **wps_sid 会话方案**：点击登录后自动弹出
WPS 网页版日历，用你的 WPS 账号登录即可完成绑定，**无需填写任何 APPID、无需企业资质**。

### 使用步骤

1. 打开新标签页 → 点击日历面板「打开 WPS 日历」（或在设置中点击「登录授权」）
2. 浏览器自动弹出 WPS 日历页面（rili.wps.cn，未登录会跳转 WPS 官方统一登录页）
3. 用你的 WPS 账号（个人 / WPS 365 均可）登录
4. 登录成功后，扩展自动读取登录会话 `wps_sid` 并完成绑定（状态变为「已登录 · 同步 WPS 日历」）
5. 之后即可在插件内 **新增 / 编辑 / 删除** 日程，实时同步到 WPS 日历

### 技术说明（wps_sid 会话方案）

| 项 | 说明 |
|---|---|
| 授权方式 | 弹出 WPS 网页版日历页，用户在浏览器中完成 WPS 账号登录 |
| 会话获取 | 扩展通过 `chrome.cookies` API 读取登录 cookie `wps_sid`（仅本机保存，不外发） |
| API 域名 | `https://rili.kdocs.cn/g-api/...` 与 `https://rili.wps.cn/g-api/...`（日历网页版内部接口，均已实测） |
| 请求头 | `Cookie: wps_sid=xxx; csrf=xxx`，`Referer/Origin` 指向 `365.kdocs.cn` |
| 已支持接口 | 查询时间段日程 / 新建 / 修改 / 删除 / 最近日程 |

> 会话有效期由 WPS 决定；失效后重新点击「登录授权」走一次弹出登录即可。
> 具体实现在 `newtab/js/wps-auth.js`（授权与会话）与 `newtab/js/wps-api.js`（日历接口）中。

## 常见问题

**Q：未登录时插件能用吗？**
能。未登录时自动使用本地模式：日程存本机，功能完整；登录后进入 WPS 同步模式。

**Q：个人 WPS 账号能同步日历吗？**
能。本插件使用 WPS 日历网页版内部接口（rili.kdocs.cn/g-api），不区分企业 / 个人账号，普通 WPS 账号登录后即可同步，无需开放平台企业资质。

**Q：wps_sid 安全吗？**
wps_sid 是你的 WPS 登录会话凭证，仅保存在本机 `chrome.storage.local`，绝不写入任何记忆 / 外部系统。请勿截图、复制或分享它。退出登录后本机保存的会话会被清除（但浏览器里已登录的 WPS 会话不受影响）。

**Q：为什么同时只能有一个新标签页插件生效？**
这是浏览器机制：`chrome_url_overrides.newtab` 同时仅允许一个扩展接管新标签页。安装本插件后 Edge 默认新标签页将不再显示。
